# 게임별 기본 포지션

- 게임 계정 화면의 롤 프로필에서 주·부 포지션을 저장한다. Riot 계정 연결 없이도 사용할 수 있다.
- 주 포지션은 TOP, JUNGLE, MID, ADC, SUPPORT, ANY 또는 미설정이다. 부 포지션은 선택 사항이며 주 포지션과 같을 수 없다. 주 포지션이 없으면 부 포지션도 없다.
- GET/PUT `/api/v1/members/me/games/{gameId}/profile`: 인증된 사용자 자신의 게임 프로필만 조회·수정한다. 현재는 league-of-legends만 지원한다.
- GET `/api/v1/meetups/{meetupId}/participation/preferences`: 서버가 맵에 따른 포지션 선택 가능 여부와 프로필 기본값을 반환한다. 활성 소환사의 협곡 맵에서만 사용한다.
- POST `/api/v1/meetups/{meetupId}/reservations`: 선택한 `primaryPosition`, `secondaryPosition`을 신청에 저장한다. 본문 생략 시 서버가 프로필 기본값을 적용하며, 둘 다 null을 명시하면 미설정으로 신청한다.
- 신청 시 수정한 값은 프로필을 변경하지 않는다. 취소 후 재신청 시 새 신청 값을 저장한다. 포지션은 선호 정보이며 역할별 좌석 배정이나 자동 매칭을 의미하지 않는다.
- V13은 사용자·게임별 프로필 테이블과 예약의 포지션 열을 추가한다. 기존 사용자와 예약은 미설정으로 유지한다. V11/V12를 포함한 순차 마이그레이션 후 프론트엔드와 백엔드를 함께 배포한다.

## 방장과 포지션 현황

- 소환사의 협곡 모임 생성 시 방장 예약에도 프로필의 주·부 포지션을 저장한다. 이후 프로필 수정은 기존 모임에 영향을 주지 않는다.
- V14는 기존 방장의 포지션이 모두 비어 있는 예약만 현재 롤 프로필로 한 번 채운다. 다른 참가자와 이미 저장된 포지션은 변경하지 않는다.
- V15는 맵 선택 도입 전에 만든 모임의 빈 맵을 명확한 게임 모드로 보완한다. 일반 교차 선택·개인/2인 랭크·자유 랭크는 소환사의 협곡, 무작위 총력전은 칼바람 나락으로 연결한다. 이미 선택한 맵과 알 수 없는 모드는 유지하며, 새로 연결된 협곡 방장의 빈 포지션도 프로필로 채운다.
- GET `/api/v1/meetups/{meetupId}/positions`는 로그인 없이 모집 포지션별 현황을 제공한다. 서버가 확정 예약만 집계하며 취소 예약은 제외한다.
- 주 포지션만 인원으로 집계한다. 부 포지션은 추가 좌석이 아니다. 미설정·ANY 인원은 별도 표시한다. 카탈로그의 BOTTOM은 프로필의 ADC와 같은 포지션이다.
- 모집 목표가 있으면 잔여 인원은 해당 목표의 잔여 인원과 전체 잔여 인원 중 작은 값이다. 목표 없는 포지션은 capacity/remainingCapacity가 null이며 현재 비어 있는지 여부만 표시한다. 역할별 선호 모집 현황으로, 별도 좌석 배정이나 역할별 참여 제한은 아니다.
- 마감된 모임의 포지션 상태는 CLOSED다. 지원하지 않는 게임·맵에서는 enabled=false다. 화면은 참여 상태 갱신 후 현황을 다시 조회한다.
