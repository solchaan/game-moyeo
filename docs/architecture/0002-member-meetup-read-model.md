# ADR 0002: 회원별 모임 조회 모델

- 상태: Accepted
- 날짜: 2026-11-03

내 모임 목록은 reservation 모듈의 공개 MyMeetupsUseCase가 소유한다. meetup/session/reservation의 읽기 전용 조인을 전용 jOOQ adapter에서 수행한다. 기존 규칙의 모듈별 테이블 격리에 대한 제한된 예외다.

회원별 필터와 시간순 페이지네이션을 한 DB 쿼리로 적용해야 하므로, 모임을 먼저 페이지네이션한 뒤 예약 API를 건별 호출하는 방식은 누락과 N+1을 만든다. 현재 단일 DB 모듈러 모놀리스에서 읽기 모델에 한해 조인을 허용한다. 쓰기는 각 모듈 유스케이스를 계속 통과한다. 독립 서비스 분리 시 이벤트 기반 projection으로 대체한다.

## 추천과 함께한 기록으로 확장

맞춤 추천과 함께한 기록도 동일한 read-model 예외를 적용한다. 회원·모임·예약 데이터를 조회 adapter에서 결합하되, 예약·알림·차단을 연결하는 쓰기는 공개 유스케이스 또는 명시된 outbox 계약을 사용한다. 차단/참가 동시성은 회원 ID 오름차순 잠금으로 직렬화한다. 알림의 읽기 모델은 별도 member_notification 테이블이며 outbox relay가 갱신한다.
