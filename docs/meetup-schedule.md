# 모임 일정

- 새 모임의 시작 시간 기본값은 작성 화면을 연 시각의 15분 뒤다. 사용자 시간대로 표시하고 API에는 UTC ISO-8601로 전송한다.
- 모임 생성·수정 요청과 목록·상세 응답에서 `endsAt`을 제거했다. 종료 시간 입력·표시·검증·저장을 하지 않는다.
- 시작 시간은 현재보다 10분 넘게 뒤여야 한다는 기존 서버 검증은 유지한다.
- OpenAPI는 `MeetupRequest`와 `MeetupView`에서 자동 생성되므로 `/v3/api-docs`에도 종료 시간 필드가 없다.
- Flyway V11은 기존 `meetup_session.ends_at`을 nullable로 변경한다. 과거 값은 보존하며 새 모임에서는 NULL이다. 구버전과의 DB 호환성을 위한 미사용 열이며, 롤백 기간 이후 별도 contract migration으로 삭제할 수 있다.
- 프론트엔드와 백엔드를 함께 배포한다. 구버전 화면을 열어둔 사용자는 새로고침이 필요하다.
